Dynamic component only. Double-integrated acceleration recovers oscillation about equilibrium, not static or quasi-static deflection. A parked/crawling load that settles the deck produces no acceleration to integrate — for absolute peak deflection under static load, use a direct sensor (LVDT, string pot) or camera-based target tracking. This tool is valid for vibration, modal and dynamic-amplification work.
CAMERA CHECK once per camera and recording mode

1 · Noise floor still recording

  1. Ground-floor concrete, quiet time. Camera on a folded towel.
  2. Same recording mode as in the field. Let it warm up ~5 min.
  3. Record 3 min without touching it; walk away.

2 · Static gain six faces

  1. Flat, level surface.
  2. Rest the camera on each of its six faces for ~10 s, then all six again (any order, one recording).
  3. Move gently between faces; don't touch it while it rests.

3 · Dynamic gain side by side with a reference sensor

  1. Fix the camera and the reference sensor rigidly to one block — clamp or bolt; no foam or tape. Line the axes up if you can; the tool pairs them either way.
  2. Camera in the field recording mode. Start both recordings, then give 3 sharp taps on the block.
  3. Shake for 2–5 min — a shaker, the structure itself, or by hand on a stiff plank — covering the frequencies you measure, at 2–3 levels (gentle, medium, strong).
  4. 3 sharp taps again, then stop both. Export the reference as CSV: time (s), then 1–3 axes.
Parts 1 and 2 check the camera at rest. Part 3 checks it while vibrating; without it, or with an uncalibrated reference, results stay labelled “dynamic gain not verified”.
